# Source code

This folder contains the Python implementation of the proposed algorithm, lower bound, instance reader, solution checker, and benchmark algorithms.

## Main files

| File | Description |
|---|---|
| `msig.py` | Proposed Multi-Start Iterated Greedy algorithm |
| `lower_bound.py` | Proposed lower-bound procedures |
| `generate_conflicts.py` | Conflict graph generation procedure |
| `instance_reader.py` | Reads BPPS/BPPSC instance files |
| `solution_checker.py` | Checks feasibility and objective value of solutions |

## Benchmark algorithms

Benchmark algorithms are stored in `src/benchmarks/`.
