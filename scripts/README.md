# Scripts

This folder contains runnable scripts for executing experiments and reproducing tables.

| File | Description |
|---|---|
| `run_single_instance.py` | Runs one algorithm on one instance |
| `run_all_by_density.py` | Runs all instances for one conflict density |
| `reproduce_tables.py` | Reproduces the computational tables reported in the paper |
| `create_summary_files.py` | Creates summary CSV/Excel files from full results |
