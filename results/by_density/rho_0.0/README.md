# Results for rho = 0.0

This folder contains computational results for BPPSC instances generated with conflict density `rho = 0.0`.

## Files

| File                                      | Description |
| ----------------------------------------- | ----------- |
| `benchmark_comparison_rho_0.0.xlsx`       | Comparison of MSIG with the adapted benchmark algorithms for all 576 instances |
| `comparison_with_best_known_BPPS.xlsx`    | Comparison of MSIG with the reported BPPS best-known solutions for the 576 conflict-free instances |
| `msig_vs_lower_bound_rho_0.0.xlsx`        | Comparison of MSIG solutions with the proposed lower bound for all 576 instances |

## Algorithms

The benchmark comparison includes:

- P-FFD
- P-BFD
- P-WFD
- Best C-TP
- MSIG

## Best-known-solution comparison

The file `comparison_with_best_known_BPPS.xlsx` compares the MSIG solution values with the reported BPPS best-known solutions for the 576 conflict-free instances.

## Lower-bound comparison

The file `msig_vs_lower_bound_rho_0.0.xlsx` compares the MSIG solution values with the proposed lower bounds for the 576 instances with `rho = 0.0`.
