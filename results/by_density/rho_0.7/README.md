# Results for rho = 0.7

This folder contains computational results for BPPSC instances generated with conflict density `rho = 0.7`.

## Files

| File                               | Description |
| ---------------------------------- | ----------- |
| `benchmark_comparison_rho_0.7.xlsx` | Comparison of MSIG with the adapted benchmark algorithms for all 576 instances |
| `msig_vs_lower_bound_rho_0.7.xlsx`  | Comparison of MSIG solutions with the proposed lower bound for all 576 instances |

## Algorithms

The benchmark comparison includes:

- P-FFD
- P-BFD
- P-WFD
- Best C-TP
- MSIG

## Lower-bound comparison

The file `msig_vs_lower_bound_rho_0.7.xlsx` reports the comparison between the MSIG solution values and the proposed lower bounds for the 576 instances with `rho = 0.7`.
