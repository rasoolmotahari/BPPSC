# Results for rho = 0.7

This folder contains computational results for BPPSC instances generated with conflict density `rho = 0.7`.

## Files

| File | Description |
|---|---|
| `results_rho_0.7.xlsx` | Full computational results for all 576 instances |
| `summary_rho_0.7.csv` | Summary by algorithm |
| `best_solutions_rho_0.7.csv` | Best solution found for each instance |

## Algorithms

- P-FFD
- P-BFD
- P-WFD
- Best C-TP
- MSIG
